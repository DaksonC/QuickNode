Referência de comandos

O QuickNode CLI tem dois comandos: qn create, que gera um projeto, e qn ui (apelido qn docs), que abre esta documentação; rode qn help <comando> para ver a mesma referência offline.

Esta página é gerada da definição que a CLI usa para ler os argumentos (src/spec.ts), então sempre corresponde à versão instalada. Os textos de ajuda da CLI ficam em inglês.
