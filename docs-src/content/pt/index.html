QuickNode CLI

Para criar uma API Node.js com arquitetura limpa, rode npx {{package}} create minha-api: você recebe Express, TypeScript ou JavaScript, PostgreSQL, testes, lint e hooks do Git, já ligados nas camadas de domínio e infraestrutura._

O {{package}} é uma CLI sem dependências para criar APIs Node.js com arquitetura limpa. A própria CLI é um único pacote npm feito só com APIs do Node.js: nada mais é baixado quando você a executa.

Não confundir com QuickNode, o provedor de infraestrutura blockchain: esta é uma ferramenta open source de scaffolding, instalada sempre pelo nome com escopo {{package}}. Usa um assistente de IA? Veja QuickNode para agentes de IA.

$ npx {{package}} create minha-api --typescript
$ cd minha-api
$ npm install
$ npm run docker:up
$ npm run dev

C:\> O que vem no projeto?

  • Arquitetura limpa: entidades, interfaces de repositório e casos de uso em src/domain; Express, banco e logs em src/infrastructure. Veja a estrutura.
  • Dois templates: TypeScript (Express, TypeORM, class-validator, tsx) ou JavaScript (Express, Sequelize, node --watch).
  • Pronto para rodar: PostgreSQL em 127.0.0.1 via Docker Compose, Swagger em /api-docs, rota de saúde, logs estruturados com pino e cabeçalhos do helmet.
  • Qualidade: Jest, ESLint 10, Prettier, Husky 9 e commitlint, com um CRUD de exemplo e seus testes.
  • Seguro por padrão: nunca grava numa pasta não vazia sem --force, rejeita nomes inseguros, gera segredos aleatórios num .env ignorado pelo git e mostra o plano com --dry-run.

C:\> Por que zero dependências?

Toda dependência de uma CLI é código rodando na sua máquina. O QuickNode usa só APIs do Node.js {{node}}+ (util.parseArgs, util.styleText, readline, fs), então o npx instala um único pacote pequeno, sem scripts de instalação. As versões são publicadas pelo GitHub Actions com provenance do npm, e cada uma pode ser rastreada até um commit. O raciocínio está no ADR-001.
