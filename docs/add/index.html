qn add recipes (coming soon)

qn add is not available yet: it is planned to apply a tool to an existing QuickNode project in one idempotent command, with --dry-run showing the diff before anything is written.

Nothing on this page works today. It lists the planned recipes so you know what is coming; the current commands are in the command reference.

C:\> How will it behave?

  • Running a recipe twice changes nothing the second time.
  • --dry-run shows the files to create or change; nothing is overwritten without --force.
  • Works without prompts in CI (--yes, --json), like qn create.
  • Recipes are data inside the CLI package: no download while they run, and still zero dependencies.

C:\> Which recipes are planned?

docker
Multi-stage Dockerfile that runs the API without root.
eslint, husky
ESLint flat config, Husky hooks and commitlint, for projects that removed them.
swagger
OpenAPI 3 setup with the UI at /api-docs.
github-actions, ci
Workflow with lint, tests, qn check and npm audit.
tests
Test runner setup with an example use case test.
auth
JWT authentication with the secret read from .env.
healthcheck
Liveness and readiness routes.
graceful-shutdown, rate-limit
Close connections cleanly on SIGTERM; limit requests per client.
agents
An AGENTS.md that tells AI coding assistants about the layers and the dependency rule.

Follow the progress in the changelog and in ADR-001, decision D6.
