Architecture decision records

QuickNode's architecture decisions are recorded as ADRs: each one states the context, the decision, the alternatives and the consequences, so you can see why the CLI works the way it does.

C:\> Which ADRs exist?

ADR-001: evolution, security and lightness of QuickNode CLI
Status: proposed, being implemented in phases. Zero runtime dependencies, safe templates, verifiable publishing, this documentation, SEO and support for AI agents.

The original of ADR-001 is written in Portuguese; the English version is a faithful translation.
