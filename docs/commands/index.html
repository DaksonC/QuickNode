Command reference

QuickNode CLI creates a project with qn create, grows it with qn generate and qn add, checks it with qn check, qn doctor and qn env, upgrades its template with qn upgrade, describes itself with qn schema, serves AI assistants with qn mcp and opens this documentation with qn ui; run qn help <command> for the same reference offline.

This page is generated from the definition the CLI parses (src/spec.ts), so it always matches the installed version.

qn create

Create a new project with clean architecture.

Usage

C:\> qn create [name] [options]

Argument

[name]
Project folder and package name ("." for the current directory)

Options

-t, --typescript
Use the TypeScript template (also -ts)
-j, --javascript
Use the JavaScript template (also -js)
-f, --force
Write into a non-empty directory, overwriting conflicting files
-y, --yes
Accept defaults without prompting (name, TypeScript, PostgreSQL)
--dry-run
Show what would be created without writing anything
--install
Install the dependencies with the --pm package manager after creating the project
--git
Initialize a git repository
--no-credits
Leave the "Generated with QuickNode" line out of the README
--pm <npm|pnpm|yarn>
Package manager used in scripts, docs and --install (default: npm)
--test <jest|node>
Test runner (default: jest; node uses the built-in node:test)
--db <postgres|sqlite|none>
Database: postgres (Docker), sqlite (node:sqlite, no driver) or none (in-memory repositories)
--preset <name|file.json>
Start from a preset (api-minima, api-postgres) or a local JSON file; flags win over it

Examples

C:\> qn create my-api
C:\> qn create my-api -ts --git --install
C:\> qn create my-api --pm pnpm --test node
C:\> qn create my-api --db sqlite
C:\> qn create my-api --preset api-minima
C:\> qn create my-api --preset ./team-preset.json
C:\> qn create . --javascript --force
C:\> qn create my-api --dry-run
C:\> qn create my-api --yes --json

qn generate

Generate a feature in the clean architecture layers, already wired.

Usage

C:\> qn generate <type> <name> [options]

Alias: qn g

Arguments

[type]
What to generate (crud = all the parts) (accepted values: crud, entity, usecase, repository, controller)
[name]
Feature name, e.g. product or order-item

Options

--only <parts>
With crud, generate only these parts (comma-separated: entity, repository, usecase, controller)
--no-test
Do not generate the use case test
--dry-run
Show the files to create or change without writing anything
-f, --force
Overwrite existing files with different content

Examples

C:\> qn generate crud product
C:\> qn g crud order-item --dry-run
C:\> qn g crud product --only entity,repository
C:\> qn g usecase product --no-test

Global options

Accepted by every command.

-h, --help
Show help
-v, --version
Show the version
--json
Print a JSON result to stdout (no prompts, no colors)

Exit codes

0
success
1
the command failed (for example, the target folder is not empty, or qn check found violations)
2
invalid usage: unknown command, flag or value

Error codes

Every error has a stable code, a short message and, when known, a fix. With --json it goes to stdout as below; without it, to stderr with a "Fix:" line. Codes never change within a major version.

C:\> qn create my-api --json
{
  "schemaVersion": 1,
  "ok": false,
  "error": {
    "code": "E_USAGE",
    "message": "Choose a template with --typescript or --javascript (or pass --yes).",
    "fix": "qn create my-api --typescript"
  }
}
E_USAGE (exit 2)
Invalid usage: unknown command, flag or value, or a missing argument
E_DIR_NOT_EMPTY (exit 1)
qn create: the target folder is not empty (use --force to write into it)
E_PATH_BLOCKED (exit 1)
qn create: a project path is taken by a file or folder of another type
E_FILES_EXIST (exit 1)
qn generate / qn add: files exist with other content (use --force to overwrite)
E_NOT_A_PROJECT (exit 1)
The command must run inside a project created with qn create
E_CONFIG_INVALID (exit 1)
quicknode.json is not valid JSON or has unknown keys or values

qn create --preset: unknown preset, unreadable file, or unknown keys or values
