Command reference

QuickNode CLI has two commands, qn create to generate a project and qn ui (alias qn docs) to open this documentation; run qn help <command> for the same reference offline.

This page is generated from the definition the CLI parses (src/spec.ts), so it always matches the installed version.

qn create

Create a new project with clean architecture.

Usage

C:\> qn create [name] [options]

Argument

[name]
Project folder and package name ("." for the current directory)

Options

-t, --typescript
Use the TypeScript template (also -ts)
-j, --javascript
Use the JavaScript template (also -js)
-f, --force
Write into a non-empty directory, overwriting conflicting files
-y, --yes
Accept defaults without prompting (name, TypeScript)
--dry-run
Show what would be created without writing anything
--install
Run npm install after creating the project
--git
Initialize a git repository
--no-credits
Leave the "Generated with QuickNode" line out of the README

Examples

C:\> qn create my-api
C:\> qn create my-api -ts --git --install
C:\> qn create . --javascript --force
C:\> qn create my-api --dry-run
C:\> qn create my-api --yes --json
Same text as qn help create 
C:\> qn help create

qn ui

Open the documentation in the browser.

Usage

C:\> qn ui [topic] [options]

Alias: qn docs

Argument

[topic]
Page to open (accepted values: start, commands, create, ui, structure, tutorial, add, faq, compare, changelog, adr)

Options

-p, --print
Only print the link, do not open the browser
--lang <en|pt>
Language of the page (default: from LANG)

Examples

C:\> qn ui
C:\> qn docs create
C:\> qn ui structure --lang pt
C:\> qn ui faq --print
Same text as qn help ui 
C:\> qn help ui
qn ui [topic] [options]

Open the documentation in the browser (alias: qn docs)

Arguments:
  topic  Page to open (start, commands, create, ui, structure, tutorial, add, faq, compare, changelog, adr)

Options:
  -p, --print         Only print the link, do not open the browser
      --lang <en|pt>  Language of the page (default: from LANG)
  -h, --help          Show help
  -v, --version       Show the version
      --json          Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn ui
  qn docs create
  qn ui structure --lang pt
  qn ui faq --print

Docs: https://daksonc.github.io/QuickNode/

Accepted by every command.

-v, --version
Show the version
--json

Exit codes

0
success
1
the command failed (for example, the target folder is not empty)
2
invalid usage: unknown command, flag or value
