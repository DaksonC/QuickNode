Referência de comandos

O QuickNode CLI tem dois comandos: qn create, que gera um projeto, e qn ui (apelido qn docs), que abre esta documentação; rode qn help <comando> para ver a mesma referência offline.

Esta página é gerada da definição que a CLI usa para ler os argumentos (src/spec.ts), então sempre corresponde à versão instalada. Os textos de ajuda da CLI ficam em inglês.

qn create

Cria um projeto novo com arquitetura limpa.

Uso

C:\> qn create [name] [options]

Argumento

[name]
Pasta e nome do pacote do projeto ("." para o diretório atual)

Opções

-t, --typescript
Usa o template TypeScript (também -ts)
-j, --javascript
Usa o template JavaScript (também -js)
-f, --force
Grava num diretório não vazio, sobrescrevendo os arquivos em conflito
-y, --yes
Aceita os padrões sem perguntar (nome, TypeScript)
--dry-run
Mostra o que seria criado sem gravar nada
--install
Roda npm install depois de criar o projeto
--git
Inicializa um repositório git
--no-credits
Deixa de fora do README a linha "Generated with QuickNode"

Exemplos

C:\> qn create my-api
C:\> qn create my-api -ts --git --install
C:\> qn create . --javascript --force
C:\> qn create my-api --dry-run
C:\> qn create my-api --yes --json
Mesmo texto de qn help create 
C:\> qn help create
qn create [name] [options]

Create a new project with clean architecture

Arguments:
  name  Project folder and package name ("." for the current directory)

Options:
  -t, --typescript  Use the TypeScript template (also -ts)
  -j, --javascript  Use the JavaScript template (also -js)
  -f, --force       Write into a non-empty directory, overwriting conflicting files
  -y, --yes         Accept defaults without prompting (name, TypeScript)
      --dry-run     Show what would be created without writing anything
      --install     Run npm install after creating the project
      --git         Initialize a git repository
      --no-credits  Leave the "Generated with QuickNode" line out of the README
  -h, --help        Show help
  -v, --version     Show the version
      --json        Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn create my-api
  qn create my-api -ts --git --install
  qn create . --javascript --force
  qn create my-api --dry-run
  qn create my-api --yes --json

Docs: https://daksonc.github.io/QuickNode/

qn ui

Abre a documentação no navegador.

Uso

C:\> qn ui [topic] [options]

Apelido: qn docs

Argumento

[topic]
Página a abrir (valores aceitos: start, commands, create, ui, structure, tutorial, add, faq, compare, changelog, adr)

Opções

-p, --print
Só imprime o link, sem abrir o navegador
--lang <en|pt>
Idioma da página (padrão: o do LANG)

Exemplos

C:\> qn ui
C:\> qn docs create
C:\> qn ui structure --lang pt
C:\> qn ui faq --print
Mesmo texto de qn help ui 
C:\> qn help ui
qn ui [topic] [options]

Open the documentation in the browser (alias: qn docs)

Arguments:
  topic  Page to open (start, commands, create, ui, structure, tutorial, add, faq, compare, changelog, adr)

Options:
  -p, --print         Only print the link, do not open the browser
      --lang <en|pt>  Language of the page (default: from LANG)
  -h, --help          Show help
  -v, --version       Show the version
      --json          Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn ui
  qn docs create
  qn ui structure --lang pt
  qn ui faq --print

Docs: https://daksonc.github.io/QuickNode/

Opções globais

Aceitas por todos os comandos.

-h, --help
Mostra a ajuda
-v, --version
Mostra a versão
--json
Imprime um resultado JSON no stdout (sem perguntas, sem cores)
