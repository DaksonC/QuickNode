Referência de comandos

O QuickNode CLI cria um projeto com qn create, faz ele crescer com qn generate e qn add, verifica com qn check, qn doctor e qn env, atualiza o template com qn upgrade, se descreve com qn schema, atende assistentes de IA com qn mcp e abre esta documentação com qn ui; rode qn help <comando> para ver a mesma referência offline.

Esta página é gerada da definição que a CLI usa para ler os argumentos (src/spec.ts), então sempre corresponde à versão instalada. Os textos de ajuda da CLI ficam em inglês.

qn create

Cria um projeto novo com arquitetura limpa.

Uso

C:\> qn create [name] [options]

Argumento

[name]
Pasta e nome do pacote do projeto ("." para o diretório atual)

Opções

-t, --typescript
Usa o template TypeScript (também -ts)
-j, --javascript
Usa o template JavaScript (também -js)
-f, --force
Grava num diretório não vazio, sobrescrevendo os arquivos em conflito
-y, --yes
Aceita os padrões sem perguntar (nome, TypeScript, PostgreSQL)
--dry-run
Mostra o que seria criado sem gravar nada
--install
Instala as dependências com o gerenciador do --pm depois de criar o projeto
--git
Inicializa um repositório git
--no-credits
Deixa de fora do README a linha "Generated with QuickNode"
--pm <npm|pnpm|yarn>
Gerenciador de pacotes usado nos scripts, na documentação e no --install (padrão: npm)
--test <jest|node>
Executor de testes (padrão: jest; node usa o node:test nativo)
--db <postgres|sqlite|none>
Banco: postgres (Docker), sqlite (node:sqlite, sem driver) ou none (repositórios em memória)
--preset <name|file.json>
Parte de um preset (api-minima, api-postgres) ou de um arquivo JSON local; as flags vencem o preset

Exemplos

C:\> qn create my-api
C:\> qn create my-api -ts --git --install
C:\> qn create my-api --pm pnpm --test node
C:\> qn create my-api --db sqlite
C:\> qn create my-api --preset api-minima
C:\> qn create my-api --preset ./team-preset.json
C:\> qn create . --javascript --force
C:\> qn create my-api --dry-run
C:\> qn create my-api --yes --json
Mesmo texto de qn help create 
C:\> qn help create

qn generate

Gera uma funcionalidade nas camadas da arquitetura limpa, já ligada.

Uso

C:\> qn generate <type> <name> [options]

Apelido: qn g

Argumentos

[type]
O que gerar (crud = todas as partes) (valores aceitos: crud, entity, usecase, repository, controller)
[name]
Nome da funcionalidade, por exemplo product ou order-item

Opções

--only <parts>
Com crud, gera só estas partes (separadas por vírgula: entity, repository, usecase, controller)
--no-test
Não gera o teste do caso de uso
--dry-run
Mostra os arquivos a criar ou alterar sem gravar nada
-f, --force
Sobrescreve arquivos existentes com conteúdo diferente

Exemplos

C:\> qn generate crud product
C:\> qn g crud order-item --dry-run
C:\> qn g crud product --only entity,repository
C:\> qn g usecase product --no-test
C:\> qn g crud product --json
Mesmo texto de qn help generate 
C:\> qn help generate
qn generate <type> <name> [options]

Generate a feature in the clean architecture layers, already wired (alias: qn g)

Arguments:
  type  What to generate (crud = all the parts) (crud, entity, usecase, repository, controller)
  name  Feature name, e.g. product or order-item

Options:
      --only <parts>  With crud, generate only these parts (comma-separated: entity, repository, usecase, controller)
      --no-test       Do not generate the use case test
      --dry-run       Show the files to create or change without writing anything
  -f, --force         Overwrite existing files with different content
  -h, --help          Show help
  -v, --version       Show the version
      --json          Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn generate crud product
  qn g crud order-item --dry-run
  qn g crud product --only entity,repository
  qn g usecase product --no-test
  qn g crud product --json

Docs: https://daksonc.github.io/QuickNode/

qn env

Compara o .env com o .env.example e gera os segredos que faltam (os valores nunca são impressos).

Uso

C:\> qn env [options]

Opções

--generate-secrets
Grava no .env as variáveis que faltam, com valores aleatórios para segredos e placeholders change-me
--dry-run
Com --generate-secrets, mostra o que mudaria sem gravar
-f, --force
Com --generate-secrets, troca também os segredos que já têm valor

Exemplos

C:\> qn env
C:\> qn env --generate-secrets
C:\> qn env --generate-secrets --dry-run
C:\> qn env --json
Mesmo texto de qn help env 
C:\> qn help env
qn env [options]

Compare .env with .env.example and generate missing secrets (values are never printed)

Options:
      --generate-secrets  Write missing variables to .env, with random values for secrets and change-me placeholders
      --dry-run           With --generate-secrets, show what would change without writing
  -f, --force             With --generate-secrets, also replace secrets that already have a value
  -h, --help              Show help
  -v, --version           Show the version
      --json              Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn env
  qn env --generate-secrets
  qn env --generate-secrets --dry-run
  qn env --json

Docs: https://daksonc.github.io/QuickNode/

qn upgrade

Aplica as melhorias de um template mais novo: atualiza os arquivos que você não alterou e mostra o diff dos outros.

Uso

C:\> qn upgrade [options]

Opções

--dry-run
Mostra o plano e os diffs sem gravar nada
-y, --yes
Aplica sem perguntar (obrigatório sem terminal)
-f, --force
Sobrescreve também os arquivos que você alterou (o diff é mostrado antes)

Exemplos

C:\> qn upgrade --dry-run
C:\> qn upgrade
C:\> qn upgrade --yes --json
Mesmo texto de qn help upgrade 
C:\> qn help upgrade
qn upgrade [options]

Apply the improvements of a newer template: updates files you did not change, diffs the rest

Options:
      --dry-run  Show the plan and the diffs without writing anything
  -y, --yes      Apply without asking (required without a terminal)
  -f, --force    Also overwrite files you changed (their diff is shown first)
  -h, --help     Show help
  -v, --version  Show the version
      --json     Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn upgrade --dry-run
  qn upgrade
  qn upgrade --yes --json

qn ui

Abre a documentação no navegador.

Uso

C:\> qn ui [topic] [options]

Apelido: qn docs

Argumento

[topic]
Página a abrir (valores aceitos: start, commands, create, ui, structure, tutorial, generate, agents, when, errors, check, add, doctor, env, upgrade, faq, compare, changelog, adr)

Opções

-p, --print
Só imprime o link, sem abrir o navegador
--lang <en|pt>
Idioma da página (padrão: o do LANG)

Exemplos

C:\> qn ui
C:\> qn docs create
C:\> qn ui structure --lang pt
C:\> qn ui faq --print
Mesmo texto de qn help ui 
C:\> qn help ui
qn ui [topic] [options]

Open the documentation in the browser (alias: qn docs)

Arguments:
  topic  Page to open (start, commands, create, ui, structure, tutorial, generate, agents, when, errors, check, add, doctor, env, upgrade, faq, compare, changelog, adr)

Options:
  -p, --print         Only print the link, do not open the browser
      --lang <en|pt>  Language of the page (default: from LANG)
  -h, --help          Show help
  -v, --version       Show the version
      --json          Print a JSON result to stdout (no prompts, no colors)

Examples:
  qn ui
  qn docs create
  qn ui structure --lang pt
  qn ui faq --print

Docs: https://daksonc.github.io/QuickNode/

Opções globais

Aceitas por todos os comandos.

-h, --help
Mostra a ajuda
-v, --version
Mostra a versão
--json
Imprime um resultado JSON no stdout (sem perguntas, sem cores)

Códigos de saída

0
sucesso
1
o comando falhou (por exemplo, a pasta de destino não está vazia, ou o qn check achou violações)
2
uso inválido: comando, flag ou valor desconhecido

Códigos de erro

Todo erro tem um código estável, uma mensagem curta e, quando conhecida, uma correção (fix). Com --json ele vai para o stdout como abaixo; sem, para o stderr com uma linha "Fix:". Os códigos não mudam dentro de uma versão major.

C:\> qn create my-api --json
{
  "schemaVersion": 1,
  "ok": false,
  "error": {
    "code": "E_USAGE",
    "message": "Choose a template with --typescript or --javascript (or pass --yes).",
    "fix": "qn create my-api --typescript"
  }
}
E_USAGE (exit 2)
Uso inválido: comando, flag ou valor desconhecido, ou argumento faltando
E_DIR_NOT_EMPTY (exit 1)
qn create: a pasta de destino não está vazia (use --force para gravar nela)
E_PATH_BLOCKED (exit 1)
qn create: um caminho do projeto está ocupado por um arquivo ou pasta de outro tipo
E_FILES_EXIST (exit 1)
qn generate / qn add: existem arquivos com outro conteúdo (use --force para sobrescrever)
E_NOT_A_PROJECT (exit 1)
O comando precisa rodar dentro de um projeto criado com qn create
E_CONFIG_INVALID (exit 1)
quicknode.json não é um JSON válido ou tem chaves ou valores desconhecidos
E_PRESET_INVALID (exit 1)
qn create --preset: preset desconhecido, arquivo ilegível ou chaves ou valores desconhecidos
E_ENV_EXAMPLE_MISSING (exit 1)
qn env: o projeto não tem .env.example para comparar com o .env
E_CONFIRM_REQUIRED (exit 1)
qn upgrade: precisa de confirmação e não há terminal (passe --yes)
E_CLI_OUTDATED (exit 1)
qn upgrade: o projeto foi criado por uma CLI mais nova que esta
E_ABORTED (exit 1)
Uma pergunta interativa foi cancelada
E_INTERNAL (exit 1)
Erro inesperado (rode de novo com DEBUG=1 e reporte)
