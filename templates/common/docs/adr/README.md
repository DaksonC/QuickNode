# Architecture decision records

Short documents that record a decision about the architecture of this project: what was
decided, why, and what follows from it. People and AI coding assistants read them before
changing the code, so a decision is not undone by accident.

- One file per decision: `NNNN-title-in-kebab-case.md`, numbered in order.
- Copy [0000-template.md](0000-template.md) to start one.
- A decision is never edited away: when it changes, write a new record and mark the old one
  as "Superseded by NNNN".
